# Valion Estúdio

Página de vendas da assinatura Valion Estúdio para profissionais da saúde.

- `index.html`: a página inteira, em um arquivo só (HTML, CSS e JavaScript), sem dependências além das fontes do Google.
- `.nojekyll`: faz o GitHub Pages servir o arquivo como está.

## Publicar

O site é servido pelo GitHub Pages a partir da branch `main`, pasta raiz. Qualquer alteração em `index.html` enviada para `main` entra no ar em cerca de um minuto.

## Trocar textos ou preços

Tudo está em `index.html`. Os cinco planos ficam na seção `<section class="plans-section" id="planos">`; o número do WhatsApp aparece nos links `wa.me/...`.
